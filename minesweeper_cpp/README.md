# 扫雷 · C++ / Win32

用原生 **Win32 API + GDI** 从零实现的经典扫雷。没有第三方库、没有图片资源（图标、7 段数码管、
笑脸按钮、3D 立体格子全部是代码画出来的），编译出来就是一个可直接分发的单文件 exe。

核心逻辑与界面完全分离：`game.cpp` 里没有一行 Windows 代码，因此可以在控制台里跑完整单元测试。

![截图](docs/screenshot.png)

## 快速开始

```powershell
# 直接运行（仓库里已带编译好的 exe）
build\Minesweeper.exe

# 自己编译（需要 VS 2022/2026 + C++ 桌面开发负载）
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

`build.ps1` 会依次编译单元测试 → 编译主程序与资源 → 运行自测，任何一步失败就中止。

## 操作

| 输入 | 作用 |
|---|---|
| 左键 | 翻开格子 |
| 右键 | 插旗 → 问号 → 取消（循环，问号可在菜单关闭） |
| 左右键同按 / 中键 | **和弦**：数字周围的旗数等于该数字时，一次翻开其余邻格 |
| 点笑脸 | 重新开始 |
| 方向键 | 移动键盘光标 |
| 空格 / F / C | 翻开 / 插旗 / 和弦 |
| F2 | 新游戏 |
| F1 | 操作说明 |

## 难度与规则

| 难度 | 尺寸 | 雷数 |
|---|---|---|
| 初级 | 9 × 9 | 10 |
| 中级 | 16 × 16 | 40 |
| 高级 | 30 × 16 | 99 |
| 自定义 | 5~50 列 × 5~30 行 | 1 ~ 宽×高-9 |

- **首点安全**：第一次点击的格子及其周围 8 格保证没有雷，开局不会一击必死（菜单里可关闭）
- **自动展开**：翻到数字 0 的格子会向外连锁展开到数字边界，用显式栈实现，30×16 也不会爆栈
- **和弦**：左右键同按展开；如果旗插错了，和弦会直接踩雷——和真实扫雷一致
- **失败表现**：踩中的雷红底显示，其余雷全部亮出，插错的旗打红叉，笑脸变成 X 眼
- **成绩记录**：三个难度的最佳用时写入注册表 `HKEY_CURRENT_USER\Software\CppMinesweeper`，
  破纪录时弹窗提示，菜单「帮助 → 关于」里可以查看

## 代码结构

```
src/game.h        核心逻辑接口（纯 C++，不含任何 windows.h）
src/game.cpp      布雷、数字计算、洪水展开、和弦、胜负判定
src/main.cpp      Win32 界面：窗口/菜单/对话框、GDI 绘制、鼠标键盘输入、注册表成绩
src/tests.cpp     单元测试（编译成独立控制台程序 tests.exe）
res/app.rc        图标与版本信息
res/app.ico       手工生成的 7 尺寸图标（16~256）
build.ps1         一键编译
docs/             截图
```

## 实现要点

- **双缓冲绘制**：所有绘制先画到内存 DC 再一次 `BitBlt` 上屏，窗口缩放/重绘都不闪烁
- **纯代码绘图**：3D 凸起/凹陷边、7 段数码管、笑脸（正常/惊讶/死亡/胜利四种表情）、
  雷（圆 + 八根尖刺 + 高光）、旗（旗杆 + 三角 + 底座）全部用 GDI 图元手绘
- **Per-Monitor V2 DPI 感知**：所有尺寸乘 DPI 缩放系数，高分屏不糊
- **静态链接 CRT**（`/MT`）：不依赖 VC 运行库，单个 exe 拷走就能用
- **逻辑零 Windows 依赖**：`game.cpp` 可单独编译测试，方便回归
- **/W4 零告警**：编译参数开了四级警告且没有使用 `#pragma warning` 压制

## 自测覆盖

`tests.exe`（11 组用例，约 441 万项断言）：

| 用例 | 校验内容 |
|---|---|
| 难度预设与重置 | 三种预设参数、雷数超限截断（9×9 上限 72）、尺寸下限、开局状态干净 |
| 首点安全 | 300 局随机首点，验证点击格及周围 8 格无雷、雷数正确 |
| 相邻雷数计算 | 每一格与暴力统计逐一对拍 |
| 洪水展开 | 展开区域不含雷；每个 0 格必须把 8 个邻居全部展开（不动点性质） |
| 胜利判定 | 翻完非雷格即判胜、自动插旗、剩余雷数归零 |
| 失败判定 | 踩雷判负、只标记一颗踩中的雷、错误插旗被标出、终局后不可再操作 |
| 插旗/问号循环 | 旗→问号→空的状态机、计数正确、已翻开格不能插旗、旗格不能被翻开 |
| 和弦展开 | 正确插旗时展开邻格；无可展开安全格时返回 false；越界/未翻开格不响应 |
| 边界与非法操作 | 负坐标、超界坐标、重复翻开 |
| 同种子可复现 | 相同种子雷区完全一致，不同种子必然不同 |
| 随机对局不变量 | 400 局随机点击（8376 次操作），每步校验：雷数守恒、插旗数与实际一致、
已翻开数与实际一致、最多一颗雷被踩中、胜利时安全格全部翻开 |

## 编译要求

- Visual Studio 2022 / 2026，安装「使用 C++ 的桌面开发」工作负载（Windows SDK 10 + MSVC x64）
- C++20

手动编译（在「x64 Native Tools 命令提示符」里）：

```bat
rc /nologo /fo build\app.res res\app.rc
cl /nologo /utf-8 /std:c++20 /EHsc /W4 /O2 /MT /DUNICODE /D_UNICODE ^
   /Fe:build\Minesweeper.exe /Fo:build\obj_gui\ src\main.cpp src\game.cpp ^
   /link /SUBSYSTEM:WINDOWS user32.lib gdi32.lib advapi32.lib build\app.res
```

> 注意 `/utf-8`：源码里有中文注释，MSVC 默认按系统代码页解析，不加这个参数会报一堆
> "字符串字面量中的换行符"之类的怪错。

## 已知限制

- 只支持 Windows（Win32/GDI），没有跨平台版本
- 没有皮肤/主题，走的是经典外观
- 不保存局面，关掉就没了（只有最佳成绩入库）
- 自定义雷区的尺寸上限是 50×30，再大普通屏幕放不下
